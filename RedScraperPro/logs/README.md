# Logs directory for RedScraperPro
This directory contains log files generated by RedScraperPro.

## Log Files
- `redscraperpro_YYYYMMDD_HHMMSS.log` - Main application logs
- Logs are automatically rotated when they reach 10MB
- Old logs are compressed and retained for 7 days

## Log Levels
- **DEBUG**: Detailed information for debugging
- **INFO**: General information about program execution
- **SUCCESS**: Successful operations
- **WARNING**: Warning messages
- **ERROR**: Error messages
- **CRITICAL**: Critical errors that may cause the program to stop

## Viewing Logs
```bash
# View latest log
tail -f logs/redscraperpro_*.log

# Search for errors
grep -i "error" logs/redscraperpro_*.log

# View specific log level
grep "SUCCESS" logs/redscraperpro_*.log
```
