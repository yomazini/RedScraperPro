    RedScrapperPro¶

    **Professional Reddit Data Scraper & Sentiment Analyzer** 🚀 [![GitHub](https://img.shields.io/badge/GitHub-RedScrapperPro-blue)](https://github.com/yomazini/RedScrapperPro) [![Python](https://img.shields.io/badge/Python-3.8%2B-blue)](https://www.python.org/) [![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

    What is RedScrapperPro?¶

    RedScrapperPro is a powerful, easy-to-use Python library for scraping Reddit data and performing sentiment analysis. Built with PRAW (Python Reddit API Wrapper), it provides a clean interface for extracting posts, comments, and user profiles.

    Key Features ✨¶

    • 🎯 Subreddit Scraping - Extract posts from any public subreddit
    • 💬 Comment Analysis - Deep-dive into comment threads
    • 👤 User Profiles - Analyze user activity and history
    • 📊 Sentiment Analysis - Built-in sentiment scoring
    • 📁 Multiple Export Formats - CSV, XLSX, TXT, JSON
    • 🎨 Beautiful CLI - Progress bars, ASCII art, and colored output
    • ⚡ Fast & Efficient - Asynchronous scraping for speed

    Quick Start 🚀¶

    Installation¶

    pip install redscraperpro

    git clone https://github.com/yomazini/RedScrapperPro.git
cd RedScrapperPro
pip install -e .

    Basic Usage¶

    from redscraperpro import RedditScraper

# Initialize scraper
scraper = RedditScraper(
    client_id="your_client_id",
    client_secret="your_secret",
    user_agent="RedScrapperPro/1.0"
)

# Scrape subreddit posts
posts = scraper.scrape_subreddit(
    subreddit="python",
    limit=100,
    time_filter="week"
)

# Add sentiment analysis
scraper.add_sentiment_analysis(posts)

# Export data
scraper.export_data(posts, format="csv", filename="python_posts.csv")

    Architecture 🏗️¶

    RedScrapperPro follows the Character System architecture for clean, maintainable code:

    graph LR
    A[API Request] --> Y[Youssef: Parser]
    Y --> H[Hassan: Validator]
    H --> Z[Zahra: Sentiment Analyzer]
    Z --> F[Fatima: Data Storage]
    F --> S[Said: Exporter]
    • Youssef (Parser) - Reads and parses Reddit API responses
    • Hassan (Validator) - Validates data and filters invalid entries
    • Zahra (Calculator) - Performs sentiment analysis and calculations
    • Fatima (Keeper) - Manages data storage and retrieval
    • Said (Presenter) - Exports data to various formats
